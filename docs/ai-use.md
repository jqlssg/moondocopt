# AI 使用说明

本次工程由参赛者 jqlssg 授权，AI 编码助手参与选题查重、docopt 移植、测试与独立差分设计、中文说明和发布操作。上一次化学领域选题没有满足参赛者对通用性的要求，因此本项目单独建仓，旧项目不覆盖、不删除。

可复核依据是：MIT 上游源代码与夹具、确定性生成器、实际编译/测试命令、真实下游输出、Git 历史和 GitHub CI。AI 的生成内容不是独立质量证明；资源上限与兼容边界已单独记录，不保证无缺陷。

真实差分曾发现新版 String.replace 只替换首处导致多单引号泄漏，修复为全量替换并保留 256 个 Python shlex 对照。所有生成测试/上游 Python/examples 均不计入生产 MoonBit 行数。没有编造用户访谈、性能数据、官方验收或报名状态。
